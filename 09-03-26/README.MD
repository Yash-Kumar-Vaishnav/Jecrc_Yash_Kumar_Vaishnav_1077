# JavaScript Event Handling Tasks (1–5)

This project demonstrates different **JavaScript Event Handling techniques** using practical scenarios commonly used in modern web applications.
Each task focuses on a specific event such as **click, keyboard input, mouse hover, and dynamic UI updates** using **Arrow Functions**.

---

# 📌 Task 1 – Button Click Event using Arrow Function

## Scenario

When the user clicks the **Login** button, the system should indicate that the login process has started.

## Requirements

* Use `addEventListener`
* Use **Arrow Function**
* Display a message in **console** and **alert**

## Key Concept

Handling **click events** using JavaScript to trigger actions when a user interacts with a button.

---

# 📌 Task 2 – Search Input Keyboard Event

## Scenario

When the user presses **Enter** inside the search box, a search action should be triggered.

## Requirements

* Use `keydown` event
* Use **Arrow Function**
* Detect **Enter key**

## Key Concept

Capturing keyboard input events and triggering functionality when a specific key is pressed.

---

# 📌 Task 3 – Button Hover Event

## Scenario

When the user moves the mouse over the **Submit** button, a message should appear in the console.

## Requirements

* Use `mouseover` event
* Use **Arrow Function**

## Key Concept

Detecting **mouse hover events** to perform actions when the cursor moves over an element.

---

# 📌 Task 4 – Input Character Counter

## Scenario

When a user types inside a **textarea**, the system dynamically displays the number of characters typed.

## Requirements

* Use `keyup` event
* Use **Arrow Function**
* Update character count dynamically

## Key Concept

Tracking user input and updating the UI in **real-time**.

---

# 📌 Task 5 – Dark Mode Toggle Button

## Scenario

When the user clicks the **Dark Mode** button, the background theme of the webpage should change.

## Requirements

* Use **Arrow Function**
* Modify **CSS using JavaScript**

## Key Concept

Using JavaScript to **toggle CSS classes** and change the appearance of the webpage dynamically.
