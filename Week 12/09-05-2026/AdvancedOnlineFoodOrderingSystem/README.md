# Advanced Online Food Ordering System

## Tech Stack
- ASP.NET Core MVC (.NET 8)
- ASP.NET Core Web API
- SQL Server
- Entity Framework Core
- ASP.NET Identity
- Docker
- Azure DevOps

## Features
- Authentication
- Admin Dashboard
- Food CRUD
- Category CRUD
- Cart System
- Checkout
- Order History
- Swagger APIs
- Responsive UI

## Run
```bash
dotnet restore
dotnet ef migrations add InitialCreate
dotnet ef database update
dotnet run
```
